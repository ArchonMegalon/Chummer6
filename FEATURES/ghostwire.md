# Ghostwire

Replay and after-action history that survives memory drift.

![Ghostwire feature art](../assets/features/ghostwire.png)

## When this helps

Use this after a session when everyone remembers the same scene differently. The point is not to litigate the table; it is to recover the sequence, compare outcomes, and write the recap while the details are still warm.

It should help a GM answer, "what actually happened?" without turning the session into a courtroom transcript.

## The table problem

People remember the drama and forget the sequence.

For example, after-action review can point at event history instead of table folklore.


## Can I use it?

There is an early version you can try. It is real enough to learn from and still rough enough that feedback matters. The next useful work is depth: steadier examples, better media, and cleaner handoff back into normal character tools.
