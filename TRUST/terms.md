# Terms in plain language

These are the plain rules for the current app: honest labels, real downloads, and straightforward support.

## Labels should say what you can install

Expect current downloads and explicit labels when compatibility or platform breadth is still moving.

## Sign-in is simple, and private help starts with Chummer

Sign-in keeps your access, devices, and help history together. Help and Contact are the normal first stops before any public feedback thread.

## Use the current public download first; advanced packages only when necessary

Public downloads should match what is honestly available right now. If a regular installer exists later, it becomes the normal path, while manual packages stay as fallback for edge cases or support-directed setup.
