# FAQ

## Start with these answers

- **Which desktop app should I start with?** Start with the Avalonia desktop app when the download page offers it.
- **What platforms are publicly available today?** Windows preview builds are the public path today unless the download page says otherwise.
- **I use Chummer5a now. Where should I start?** Start with [What Chummer6 Is](WHAT_CHUMMER6_IS.md) and [Current status](NOW/current-status.md).
- **Do I need GitHub for anything normal?** No. Use the guide, download page, and help flow first.

## Questions people actually ask first

### Can I actually use this now?

Yes. Chummer6 is still preview software, but the preview is real: there are live downloads, current pages, and clear labels for what is still rough.

### Is it offline-safe?

That is one of the core goals. Chummer6 is being built so bad connectivity does not destroy your flow or your work.

### Why would I trust it more than old opaque tool behavior?

Because Chummer6 tries to show why a result changed instead of leaving you with a number and no explanation.

### What is preview versus available today?

Available today means you can open it or download it right now. Preview means you can use it, but parts of the release, compatibility, or support story are still changing.

### What should I show a skeptical GM or player first?

Start with [What Chummer6 Is](WHAT_CHUMMER6_IS.md), then [Status](STATUS.md), then [Download](DOWNLOAD.md). If the real argument is about how the math is explained, show them [Core](PARTS/core.md).

## When something is weird or broken

### How do I report something?

Start with Help or Contact. If you want to help test or shape a fix in public, use the participation page.

### Can I help with fixes or testing?

Yes. The participation page explains hands-on help for people who want to do more than leave feedback. It does not replace normal bug reports.

### Do I need to join anything to help?

No. Normal bug reports, documentation feedback, and feature requests still matter.

### Should I use the participation page for a crash?

No. Use the private crash or support path when logs or diagnostics are involved. Use the participation page only for safe public follow-up.

### Why are some things preview-only?

Because some parts are good enough to try before every platform, install flow, and support path is equally polished.

### Will preview access open wider later?

That is the goal. Early access may stay narrow while support cost, polish work, or approvals are still unusually high.

### Can I participate privately?

Yes. Public recognition should remain opt-in, and private participation should still be possible even when badges or leaderboards exist.

### What are badges and leaderboards for?

They are thank-yous, not power. They should celebrate useful help without replacing review or the rules themselves.

### Would I need a Windows PC to join a run?

No. The intended direction is that browsing runs, applying with a quickstart or approved runner, acknowledging table expectations, and receiving schedule and session details should work without assuming a Windows-only setup.

### Is Chummer trying to replace Discord or VTTs?

No. Chummer should handle rules, applications, scheduling records, and campaign consequences while Discord, Teams, and VTTs stay useful places to talk and play.
