# Current Status

Chummer is available today as a Windows and Linux desktop download. Use the live status page for the exact current build, release time, and platform notes.

## What works today

- Windows and Linux are the normal public install paths.
- Stable is the slower channel.
- Nightly is the newest rolling public build for Windows and Linux.
- Help, recovery, issue reporting, privacy, and terms pages are live.
- Account linking is optional unless you want support history, recovery, or return access tied to your account.

## Not posted today

- macOS is not a normal public download path today.
- ARM builds are not normal public download paths today.
- Campaign and media features are still being separated from the core character-building path.
